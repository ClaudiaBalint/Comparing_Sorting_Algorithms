# Android App for Sorting Algorithms

An Android application developed in Java for learning and exploring sorting algorithms through explanations, implementations and comparisons.

## Technologies

- Java
- Android Studio
- Android SDK

## Implemented Algorithms

- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Selection Sort

## Features

- Sorting algorithm implementations
- Theoretical explanations of the algorithms
- Step by step sorting
- Algorithm comparison
- Algorithm testing

## Project Structure

The main application code is located in:

`src/main/java/com/example/proiect/`

The project includes separate classes for each sorting algorithm and additional classes for explanations, testing, animation, and algorithm comparison.

## Assets

The `assets` directory contains text files with information related to the implemented sorting algorithms.

## Testing

The project contains Android instrumented tests and unit tests under:

- `src/androidTest/`
- `src/test/`

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Android Studio to install or configure the required dependencies.
4. Build and run the application on an Android device or emulator.
